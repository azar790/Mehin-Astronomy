## ✨ Features (Xüsusiyyətlər)

- 📱 **Mobile & iPhone-Optimized Responsive Layout:**
  - Designed from the ground up for smartphones (iPhone & Android) and tablets.
  - Zero text wrapping or awkward badge breaks (`whitespace-nowrap`), silky smooth touch scrolling, and zero horizontal overflow.

- 🧑‍🚀 **Animated Cosmic Background (Canlı Kosmik Fon):**
  - **Full-Body Floating Astronaut:** An animated vector astronaut with waving arms, walking boots, and visor reflections gently floating within screen bounds.
  - **Periodic Star Rocket & Meteor Shower:** A friendly space rocket and falling meteor clusters smoothly gliding across the night sky in timed, peaceful turns.

- ☀️ **Live Sun Journey & 🌙 Moon Phase Radar:**
  - Real-time **Sunrise & Sunset** calculation with an animated daylight progress arc.
  - Live **Moon Phase & Illumination %** tracker (Crescent, Quarter, Gibbous, Full Moon, and Blood Moon alerts).
  - Countdown timer to the next Full Moon ("Full Moon in 3 days!").

- 🌦️ **5-Day Compact Weather Forecast (5 Günlük Hava Proqnozu):**
  - Positioned seamlessly directly beneath the Sun & Moon radar.
  - Perfectly fit 5-day grid (`grid-cols-5`) tailored for mobile screens with **zero horizontal scrolling needed**.
  - Shows daily high/low temperatures, precipitation chance (rain/snow %), and wind speed (km/h) powered by Open-Meteo.
  - Interactive day-by-day modal popup with kid-friendly sky watching tips and weather descriptions.

- 🔭 **Next 7 Days Wonder Radar (Növbəti 7 Günün Möcüzələri):**
  - Displays upcoming world festivals, astronomical milestones, and cultural days strictly occurring in the **next 7 days**.
  - Single, distraction-free continuous feed (no confusing tabs or missions).
  - Confetti celebration button on today's featured wonder!

- 🌍 **Rich World Celebrations & Azerbaijani Heritage:**
  - Global celebrations: Brazil Carnival 🇧🇷, India Holi 🇮🇳, Japan Sakura 🌸, USA 4th of July 🎆, Spain La Tomatina 🍅.
  - Kids & Family Days: International Children's Day 🎈, Mother's Day 💐, Father's Day 👔, World Cat Day 🐱, World Literacy Day 📚.
  - Azerbaijani Cultural Days: Novruz Bayramı 🌺, Su, Od, Yel və Torpaq çərşənbələri, Dövlət Bayrağı Günü 🇦🇿.

- 🎨 **5 Beautiful Color Themes (5 Rəng Teması):**
  - **Cosmic Night 🌌:** Deep space, glowing nebula, and twinkling stars.
  - **Sunset Glow 🌇:** Warm golden sunset, peach skies, and evening twilight.
  - **Emerald Aurora 💚:** Northern lights green with shimmering emerald glows.
  - **Star Candy 🦄:** Pastel pink and magical fairy tale starlight.
  - **Sunny Sky ☀️:** Bright cheerful daylight sky with golden sunshine.

- ⚙️ **Explorer Control Center (Ayarlar):**
  - Personalize explorer name (defaults to **Mehin**).
  - Choose explorer avatar (Cadet 🧑‍🚀, Star Princess ⭐, Comet Rider 🚀, Alien Pal 👽, Astro Kitty 🐱‍🚀).
  - Language toggle: **English 🇬🇧 / Azərbaycan 🇦🇿**.
  - Geolocation detection (GPS) or quick city selector (Baku, London, New York, Tokyo, Istanbul, Paris).

## 🛠️ Tech Stack

- **Frontend:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 + Hardware-Accelerated Gradients
- **Animations:** Framer Motion + CSS Keyframes
- **Icons:** Lucide React
- **Astronomy Calculations:** SunCalc v2 (astronomical solar & lunar formulas)
- **Weather API:** Open-Meteo (real-time temperature, precipitation & wind)
- **Effects:** Canvas-Confetti

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/azar790/Mehin-Astronomy.git
cd Mehin-Astronomy
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser!

### 4. Build & Preview for Mobile / Production
```bash
npm run build
npm run preview -- --host --port 5173
```
Access `http://<your-local-ip>:5173` on your iPhone or mobile device over local Wi-Fi.
